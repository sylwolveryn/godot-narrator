## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The narrator is the story's voice in M1 and must show morphing ASCII text with ambient sound. The beats must be triggered by events or time, not hard-coded into scenes, so later beats can be added as data.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Narration text assembles on screen as morphing ASCII text using the presentation approach chosen by the spike.
- [x] #2 Ambient SFX plays alongside narration when a beat is triggered.
- [x] #3 Narration beats are data-driven (resource or exported list) and each beat specifies its trigger (event or time).
- [x] #4 Narration progress persists: a beat already heard does not repeat in later runs, and new beats unlock by run or death count
- [x] #5 Beats can be gated by run count so tone can shift from cryptic to clearer over runs
- [x] #6 M1 beats hint at contradicting origins (e.g. hero vs villain, alien, AI, demonic, angelic) and never state one answer
<!-- AC:END -->
